# RIFF

RIFF is a guitar tab and video editor for creating vertical music tutorial videos.

## Current working base

The current local working base is RIFF v47 (`RIFF_v47_video_and_tab_switch_fix.html`). It is not yet browser-validated. This repository is intended to preserve versions and track changes.

## Workflow
- Keep the stable base unchanged.
- Make focused changes on a separate working version.
- Validate browser behavior before promoting a version.
- Record each change in commits.
